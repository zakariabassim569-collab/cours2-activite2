# Cours 2 - Activité 2: React

Hi! 👋

This is my second activity using React as part of my front-end development course at ESTL.

## 📌 About the project

In this project, I created a simple user profile using React. I practiced dividing my code into different components and passing data between them using props.

The profile contains:
- The user's name, age, and profession
- Objectives
- Motivations
- Frustrations

## 🛠️ Technologies

- React
- JavaScript
- HTML
- CSS

## 📚 What I learned

While working on this activity, I learned how to:
- Create React components
- Use props to pass data to components
- Display lists using `map()`
- Write JSX code

## ▶️ How to run the project

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the project:

   ```bash
   npm run dev
   ```

*Note: This command is for Vite projects.*
